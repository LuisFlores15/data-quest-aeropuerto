# Data Quest: Crisis en el aeropuerto

Experiencia gamificada para aprender análisis de datos, SQL e IA responsable a
partir de reclamaciones aeroportuarias.

## Estado
🚧 En construcción — versión 0.1

## Propósito
Transformar datos imperfectos en decisiones empresariales justificadas.

## Tecnologías previstas
Python · Jupyter/Colab · SQL · Visualización de datos · IA responsable

## Aviso
Este es un caso educativo. No representa una evaluación oficial de aeropuertos,
aerolíneas, concesionarios ni entidades reales.
